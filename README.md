# 📚 Smart Document Knowledge Assistant

A 🤖 RAG-based web application that helps students quickly ask questions about their 📄 PDF and 📝 TXT documents.

## ✨ Features

- 📤 Upload PDF and TXT files
- ✂️ Split documents into smaller chunks
- 🧠 Create text embeddings
- 🔍 Find the most relevant document sections
- 💬 Ask questions about your documents
- 🤖 Generate answers using an LLM
- 📌 Show referenced document snippets and page numbers
- 🔄 Supports follow-up questions

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Streamlit
- ✨ Google Gemini API
- 🔢 NumPy
- 📄 PyPDF
- 🧩 LangChain Text Splitters

## ⚙️ How It Works

1. 📤 Upload documents
2. 📖 Extract the text
3. ✂️ Split the text into chunks
4. 🧠 Create embeddings
5. 🔍 Find the most relevant chunks
6. 📋 Send the retrieved context to the LLM
7. 💬 Generate an answer with source references

## 🎯 Purpose

Built to make studying and working with large collections of lecture notes, lab manuals, and research documents easier and faster.
